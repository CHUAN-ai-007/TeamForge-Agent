🏷️ 创建 GitHub Release

版本: v2.4.2

1
点击下方按钮打开 GitHub 发布页面

会自动跳转到创建 Release 的页面

2
选择标签

在 "Choose a tag" 下拉框中选择 v2.4.2

3
填写发布信息

复制以下内容粘贴到发布说明中：

## v2.4.2 更新内容 ### 新功能 - 首页组织架构脑图展示 - Agent 拖拽排序功能修复 - 导航栏显示版本号 V 2.4.2 ### 优化 - AI 模型测试错误提示优化 - 数据兼容性处理 ### 修复 - Agent 排序不生效问题
4
点击发布

点击 "Publish release" 按钮完成发布

打开 GitHub 发布页面
